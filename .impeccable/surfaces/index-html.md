# Surface Brief — Social Intelligence Workspace

Mode: Operate
Primary target: index.html
Seed key: d2cb1bde

The user fixed the product workflows and Airtable editorial visual language, then explicitly asked for a complete, modern, wow-level redesign without stopping for more questions. The build therefore preserves familiar operator affordances while replacing the prototype composition and generic module treatment.

## Direction contract

**THESIS:** A live intelligence command desk organized by decisions rather than widgets. The page refuses the equal-card SaaS wall: what changed, why it matters, the evidence behind it, and the next action must read as one continuous investigation surface.

**OWN-WORLD:** Bright white work canvas, cool paper-gray shell, near-black ink, hairline rules, and selective full-surface coral, forest, cream, mint, peach, mustard, and dark-navy analytical moments. Typography remains neutral and workmanlike at regular/medium weights; hierarchy comes from scale, spacing, position, and data density. Controls use a single coherent 6/10/12px radius system with shadows reserved for floating layers.

**STORY:** The operator opens to a concise live brief, sees one dominant movement and a ranked signal rail, checks the compact KPI ribbon, and drills straight into evidence. From there the same shell carries search, monitored posts, keywords, competitors, reports, automation, AI, team, and system operations with route-specific state and actions instead of repeated generic placeholders.

**FIRST VIEWPORT:** Desktop uses a 68px utility bar and 272px grouped navigation rail. The work canvas starts with a quiet title/action band, then an integrated brief ribbon: current listening state and five metrics live on one horizontal editorial plane. Beneath it, a 12-column command field gives roughly eight columns to the engagement narrative and four to a solid-color signal rail. A compact evidence queue peeks into the same viewport so every chart has an immediate path to source material.

**FORM:** Investigation cockpit / command-desk structure selected from the surface roll. Familiar navigation, filters, tables, drawers, dialogs, and keyboard search stay standard; the composition is made distinctive through asymmetry, strong editorial pacing, persistent evidence paths, and one authored state transition rather than decorative animation. Surface concept seed `d2cb1bde` is the structural source; the supplied Airtable visual direction remains the identity authority.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
